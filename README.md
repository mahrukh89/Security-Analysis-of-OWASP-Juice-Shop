Introduction
This quick-reference guide outlines exactly what each file in this repository contains and its purpose in our OWASP Juice Shop Security Project.

 File Map

JUICE_SHOP_CMD_GUIDE.md

A step-by-step terminal guide specifically for Windows Command Prompt (cmd.exe) to quickly pull, run, test, and shut down the Juice Shop container.

Threat_Modeling_Report.pdf 

The comprehensive threat modeling document detailing critical system threats, architectural risk analysis, and OWASP Top 10 mapping.

Core Project Scope 
Analyzed: Performed a threat model and architectural review of the OWASP Juice Shop web app.

Exploited: Conducted Proof-of-Concept (PoC) validation on SQL Injection, Cross-Site Scripting (XSS), and Broken Access Control.

Remediated: Documented and verified code-level fixes (Parameterized Queries, Context-Aware Encoding, and JWT-based Middleware) to secure the application.
